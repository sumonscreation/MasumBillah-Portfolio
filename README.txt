Muhammad Masum Billah — Portfolio Website

Responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

Run locally
Open index.html in a modern browser. No build tools or framework are required.

Project files
- index.html — page structure and portfolio content
- style.css — responsive layout, gallery styling and motion effects
- script.js — mobile navigation, project filters and scroll reveals
- assets/projects/ — the eight supplied website portfolio images
- assets/graphics/ — eleven supplied graphic design portfolio images
- assets/ — supplied profile photos, CV PDF and Sumon's Creation logo

Gallery notes
- The eight image previews are shown in their original proportions without cropping.
- Hovering a card reveals a viewing prompt and gently zooms the image.
- Category buttons filter healthcare, home services, and property/build projects.
- The designs are presented as portfolio visuals based on the supplied images. Add live URLs or case-study details when available.
- Animations respect the visitor's reduced-motion setting.
- The supplied Sumon's Creation logo is used in the navigation, footer and browser tab icon. Its full-resolution original is also included.
- The visual theme uses matte black with the logo's indigo and orange colors.
- Graphic design work has its own gallery and category filters for backgrounds, logo concepts, invitations and flyers. Repeated logo attachment is shown once.

Publishing
Upload the complete masum-portfolio folder to your web host. Keep the assets folder alongside index.html. The Google Fonts link requires an internet connection; system font fallbacks are included.
